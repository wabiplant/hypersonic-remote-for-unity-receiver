HyperSonic Remote for Unity Receiver

Unity Editor で再生中のゲームを iPhone から低遅延で操作するための受信パッケージです。
The Unity-side receiver for HyperSonic Remote, an iPhone app that turns your phone into a low-latency touch pad for the Unity Editor.

導入方法 (Setup)

  1. Unity の Package Manager で + → Add package from git URL… を選び、次の URL を貼ります:
    https://github.com/wabiplant/hypersonic-remote-for-unity-receiver.git
  2. お使いの Unity プロジェクトで Play を押します。受信は自動で起動します（シーンへの追加作業は不要です）。
  3. iPhone アプリ HyperSonic Remote を開き、表示されたコンピューターを選んで接続します。

パソコン側に追加で入れるものはありません（Wi-Fi でも USB でも、別途のアプリやコマンドは不要です）。導入の詳細は GitHub リポジトリ をご覧ください。

困ったときは (Troubleshooting)

  • コンピューターが見つからない: iPhone とパソコンが同じ Wi-Fi ネットワークにあるか確認してください。初回はパソコン側で Unity の「ローカルネットワーク」へのアクセス許可が必要です。
  • つながるのに操作が効かない: Unity で Play 中かどうか確認してください。受信は Play 中のみ動作します。
  • USB で使いたい: ケーブルで iPhone とパソコンを繋ぎ、アプリで USB を選ぶだけです（追加のソフトやコマンドは不要です）。
